Bienvenue sur le site de documentation des APIs Freebox

Le SDK Free est un ensemble d'APIs destiné aux développeurs indépendants, leur permettant de développer des applications qui fonctionnent sur ou avec la Freebox Révolution ou Delta. Il est constitué de quatre grandes parties actuellement :

  • le SDK QML basé sur le langage QML et le module fbx pour vos applications sur le Player
  • la partie native reservée actuellement aux éditeurs partenaires
  • le protocole de télécommande réseau pour interagir avec le boitier Player
  • la partie FreeboxOS pour communiquer avec le boitier Server
