======
Switch
======

The Switch API allow you to control the settings of the Freebox
integrated switch.

Switch Errors
=============

When attempting to access the switch API, you may encounter the
following errors:

======================           ======================
error_code                       Description
======================           ======================
bad_port                         invalid port number
bad_speed                        unable to set port speed
bad_link                         unable to set port link mode
bad_mac_entry_type               invalid mac entry type
======================           ======================

Switch Port Status Object
=========================

SwitchPortStatus has the following attributes:

.. json:object:: SwitchPortStatus

   .. json:property:: id int [ro]

       switch port id

   .. json:property:: link enum [ro]

      ======================           =========================
      link                             Description
      ======================           =========================
      up                               port is up
      down                             port is down
      ======================           =========================

   .. json:property:: duplex enum

      ======================           =========================
      duplex                           Description
      ======================           =========================
      half                             force in half duplex mode
      full                             force in full duplex mode
      ======================           =========================

   .. json:property:: speed enum

      ======================           =========================
      duplex                           Description
      ======================           =========================
      10                               10Base-T
      100                              100Base-TX
      1000                             1000Base-T
      ======================           =========================

   .. json:property:: mode string [ro]

      display form of speed and duplex mode

   .. json:property:: mac_list object[] [ro]

      list of { mac, name } of hosts connected to this port


Switch Port Configuration Object
================================

SwitchPortConfig has the following attributes:

.. json:object:: SwitchPortConfig

   .. json:property:: id int [ro]

       switch port id

   .. json:property:: duplex enum

      ======================           =========================
      duplex                           Description
      ======================           =========================
      auto                             auto negotiate duplex mode
      half                             force in half duplex mode
      full                             force in full duplex mode
      ======================           =========================

   .. json:property:: speed enum

      ======================           =========================
      duplex                           Description
      ======================           =========================
      auto                             auto negotiate speed
      10                               10Base-T
      100                              100Base-TX
      1000                             1000Base-T
      ======================           =========================

Switch API
==========

Get the current switch status
-----------------------------

.. http:get:: /api/v4/switch/status/

   Return the list of swith port status :json:object:`SwitchPortStatus`

   **Example request**:

   .. sourcecode:: http

      GET /api/v4/switch/status/ HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": [
              {
                  "duplex": "half",
                  "link": "down",
                  "id": 3,
                  "mode": "10BaseT-HD",
                  "speed": "10"
              },
              {
                  "duplex": "full",
                  "link": "up",
                  "id": 1,
                  "mode": "1000BaseT-FD",
                  "speed": "1000"
              },
              {
                  "duplex": "half",
                  "link": "down",
                  "id": 2,
                  "mode": "10BaseT-HD",
                  "speed": "10"
              },
              {
                  "duplex": "full",
                  "mac_list": [
                      {
                          "mac": "00:24:D4:7E:00:4C",

Get a port configuration
------------------------

.. http:get:: /api/v4/switch/port/{id}

   Get the :json:object:`SwitchPortConfig` for the given port id

   **Example request**:

   .. sourcecode:: http

      GET /api/v4/switch/port/1 HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "id": 1,
              "speed": "auto",
              "duplex": "auto"
          }
      }

Update a port configuration
---------------------------

.. http:put:: /api/v4/switch/port/{id}

   Update the :json:object:`SwitchPortConfig` for the given port id

   **Example request**:

   .. sourcecode:: http

      PUT /api/v4/switch/port/1 HTTP/1.1
      Host: mafreebox.freebox.fr

   .. sourcecode:: javascript

      {
         "speed": "10"
      }

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "id": 4,
              "speed": "10",
              "duplex": "auto"
          }
      }
