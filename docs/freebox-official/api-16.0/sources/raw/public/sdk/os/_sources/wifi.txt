=====
Wi-Fi
=====

The Wi-Fi API allow you to control the settings of the Freebox Wi-Fi.

Wi-Fi Errors
============

When attempting to access this API, you may encounter the following
errors:

======================           ============================================================
error_code                       Description
======================           ============================================================
inval                            invalid parameters
exist                            entry already exists
nospc                            maximum entry count reached
nodev                            invalid device id
noent                            invalid id
busy                             device busy
inval_band                       invalid wifi band
inval_ssid                       invalid ssid
inval_freq                       invalid wifi frequency
inval_cipher                     invalid cipher mod
inval_key_len                    invalid key length
inval_key                        invalid key
inval_ht_mode                    invalid 802.11n mode
inval_ht_mode                    invalid wifi frequency for this 802.11n mode
inval_ht_needs_wmm               wmm must be enabled for 802.11n
inval_ac_needs_ht                invalid configuration 802.11ac need ht support
inval_ac_not_2d4g                invalid configuration 802.11ac is not supported on 2.4G band
======================           ============================================================

Wi-Fi Global Config
===================

Global config gives quick access to major configuration settings (eg: toggle Wi-Fi)

WifiGlobalConfig has the following attributes:

.. json:object:: WifiGlobalConfig

   .. json:property:: enabled bool

      is wifi enabled

   .. json:property:: mac_filter_state enum

      ================   =========================================
      mac_filter_state   Description
      ================   =========================================
      disabled           mac filter is disabled
      whitelist          mac filter is enabled, using a whitelist
      blacklist          mac filter is enabled, using a blacklist
      ================   =========================================

Wi-Fi global config API
=======================

Get the current Wi-Fi global configuration
------------------------------------------

.. http:get:: /api/v2/wifi/config/

   Get the :json:object:`WifiGlobalConfig`

   **Example request**:

   .. sourcecode:: http

      GET /api/v2/wifi/config/ HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "enabled": true,
              "mac_filter_state": "blacklist"
          }
      }

Update the Wi-Fi global configuration
-------------------------------------

.. http:put:: /api/v2/wifi/config/

   Update the :json:object:`WifiGlobalConfig`

   **Example request**:

   .. sourcecode:: http

      PUT /api/v2/wifi/config/ HTTP/1.1
      Host: mafreebox.freebox.fr

   .. sourcecode:: javascript

      {
         "enabled": false
      }

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "enabled": false,
              "mac_filter_state": "blacklist"
          }
      }

Wi-Fi Access Point
==================

Wi-Fi AP objects
----------------

The Freebox may have one or more access points, you can configure each access point with this api.

.. json:object:: WifiAp

   .. json:property:: id int [ro]

      wifi ap id

   .. json:property:: name string [ro]

      wifi ap name

   .. json:property:: status WifiApStatus [ro]

      ap status

   .. json:property:: capabilites WifiApCapabilities [ro]

      ap capabilities

   .. json:property:: config WifiApConfig

      ap configuration

.. json:object:: WifiApStatus

   .. json:property:: state enum [ro]

      =================  ===================================================
      state              Description
      =================  ===================================================
      scanning           Ap is probing wifi channels
      no_param           Ap is not configured
      bad_param          Ap has an invalid configuration
      disabled           Ap is permanently disabled
      disabled_planning  Ap is currently disabled according to planning
      no_active_bss      Ap has no active BSS
      starting           Ap is starting
      acs                Ap is selecting the best available channel
      ht_scan            Ap is scanning for other access point
      dfs                Ap is performing dynamic frequency selection
      active             Ap is active
      failed             Ap has failed to start
      =================  ===================================================

   .. json:property:: channel_width int [ro]

      effective channel width (in MHz)

    .. json:property:: primary_channel int [ro]

      effective primary channel

    .. json:property:: secondary_channel int [ro]

      effective secondary channel

    .. json:property:: dfs_cac_remaining_time int [ro]

      time left in dfs state

.. json:object:: WifiApCapabilities

    [UNSTABLE]

   .. json:property:: 2d4g int [ro]

      map of capabilites in 2.4 GHz band

   .. json:property:: 5g int [ro]

      map of capabilites in 5 GHz band

   .. json:property:: 60g int [ro]

      map of capabilites in 60 GHz band

NOTE: before enabling some feature in ap config, you should ensure that AP supports the
feature using its provided capabilities.


.. json:object:: WifiApHtConfig

    .. json:property:: ac_enabled bool

      enable 802.11ac

    .. json:property:: ht_enabled bool

      enable 802.11n

      [UNSTABLE]

.. json:object:: WifiApConfig

    .. json:property:: band enum

       ========   ================
       band       Description
       ========   ================
       2d4g       2.4 GHz
       5g         5 GHz
       60g        60 GHz
       ========   ================

    .. json:property:: channel_width int

       wanted channel width (in MHz) :

         -  20 MHz
         -  40 MHz
         -  80 MHz
         - 160 MHz

    .. json:property:: primary_channel int

      wanted primary channel, value of 0 means automatic selection

    .. json:property:: secondary_channel int

      wanted secondary channel, value of 0 means automatic selection

    .. json:property:: dfs_enabled bool

      enable channels that require DFS

    .. json:property:: ht WifiApHtConfig

      wifi ht config

Wi-Fi AP allowed channels
-------------------------

To be able to allow user to pick a valid channel combination for a given AP you should use
the following api to retreive the list of allowed channel combination.

.. json:object:: WifiAllowedComb

   .. json:property:: band enum [ro]

       the band for which the combination can be used

       ========   ================
       band       Description
       ========   ================
       2d4g       2.4 GHz
       5g         5 GHz
       60g        60 GHz
       ========   ================

   .. json:property:: channel_width string [ro]

       the channel_width for which the combination can be used

   .. json:property:: need_dfs bool [ro]

       does this combination requires DFS.

       You should only allow this combination if ap has allowed dfs.

   .. json:property:: dfs_cac_time int [ro]

       time required in dfs state before behing able to start the AP.

   .. json:property:: primary int [ro]

      primary channel

   .. json:property:: secondary int [ro]

      secondary channel (zero means that secondary channel will not be used)


.. http:get:: /api/v2/wifi/ap/{id}/allowed_channel_comb

   Get the :json:object:`WifiAllowedComb` for the given ap id

   **Example request**:

   .. sourcecode:: http

      GET /api/v2/wifi/ap/0/allowed_channel_comb HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

Wi-Fi AP stations
-----------------

Wi-Fi AP Stations objects
^^^^^^^^^^^^^^^^^^^^^^^^^

WifiStation has the following attributes:

.. json:object:: WifiStation

   .. json:property:: id string [ro]

      station id

   .. json:property:: mac string [ro]

      client MAC address

   .. json:property:: bssid string [ro]

      bssid on which the client is associated

   .. json:property:: hostname string [ro]

      client host name

   .. json:property:: host LanHost [ro]

      client host information

   .. json:property:: state enum [ro]

      ===============  ===========================
      state            Description
      ===============  ===========================
      associated       station is associated
      authenticated    station is authenticated
      ===============  ===========================

   .. json:property:: inactive int [ro]

      inactive duration (in seconds)

   .. json:property:: conn_duration int [ro]

      connection duration (in seconds)

   .. json:property:: rx_bytes int [ro]

      received bytes (from station to Freebox)

   .. json:property:: tx_bytes int [ro]

      transmitted bytes (from Freebox to station)

   .. json:property:: tx_rate int [ro]

      reception data rate (in bytes/s)

   .. json:property:: rx_rate int [ro]

      transmission data rate (in bytes/s)

   .. json:property:: signal int [ro]

      signal attenuation (in dB)

   .. json:property:: flags WifiStationFlags [ro]

      station flags

   .. json:property:: last_rx WifiStationStats [ro]

      last rx stats

   .. json:property:: last_tx WifiStationStats [ro]

      last tx stats

.. json:object:: WifiStationFlags

      [UNSTABLE]

   .. json:property:: legacy bool [ro]

      does station uses legacy wifi (802.11a, 802.11b)

   .. json:property:: ht bool [ro]

      does station support ht (802.11n)

   .. json:property:: vht bool [ro]

      does station support vht (802.11ac)

   .. json:property:: authorized bool [ro]

      is the station authenticated

.. json:object:: WifiStationStats

      [UNSTABLE]

   .. json:property:: bitrate int [ro]

      physical link rate (in 1/10th of MBit/s), -1 if unknown

   .. json:property:: mcs int [ro]

      current link mcs, -1 if not used

   .. json:property:: vht_mcs int [ro]

      current link vht mcs, -1 if not used

   .. json:property:: width string [ro]

      current channel width

   .. json:property:: shortgi bool [ro]

      is shortgi enabled

Wi-Fi BSS
=========

Each AP can manage a set of BSS, with this api you can manage BSS settings

Wi-Fi BSS objects
-----------------

.. json:object:: WifiBss

   .. json:property:: id int [ro]

      bss id

   .. json:property:: phy_id string [ro]

      associated AP id

   .. json:property:: status WifiBssStatus [ro]

      bss status

   .. json:property:: config WifiBssConfig

      bss configuration

.. json:object:: WifiBssStatus

   .. json:property:: state enum [ro]

      =================  ===================================================
      state              Description
      =================  ===================================================
      phy_stopped        associated AP is stopped
      no_param           bss is missing config
      bad_param          bss has an invalid config
      disabled           bss is disabled
      starting           bss is starting
      active             bss is active
      failed             bss has failed to start
      =================  ===================================================

   .. json:property:: sta_count int [ro]

      number of stations for this bss

    .. json:property:: authorized_sta_count int [ro]

      number of authenticated stations for this bss

    .. json:property:: is_main_bss bool [ro]

      if bss is main bs, its configuration will be reused for other bss with
      attribute use_default_config set as true. This can be used to apply the
      same configuration to 2 bss on 2 AP operating on different wifi bands.

.. json:object:: WifiBssConfig

    .. json:property:: enabled bool

      enable this BSS. Note that if you want the AP to completely stop emitting wifi
      you should use :json:object:`WifiGlobalConfig` enabled attribute, otherwise
      FreeWifi and FreeWifi Secure may still be active.

   .. json:property:: use_default_config bool

      if true, share the configuration with the main bss

    .. json:property:: ssid str

      bss displayed name

    .. json:property:: hide_ssid str

      don't show bss in bss list

    .. json:property:: encryption enum

      ================ ======================
      encryption       Description
      ================ ======================
      wep              wep (should not use)
      wpa_psk_auto     wpa/psk auto
      wpa_psk_tkip     wpa/psk tkip
      wpa_psk_ccmp     wpa/psk ccmp
      wpa2_psk_auto    wpa2/psk auto
      wpa2_psk_tkip    wpa2/psk tkip
      wpa2_psk_ccmp    wpa2/psk ccmp
      ================ ======================

   .. json:property:: key string [wo]

      wifi key

   .. json:property:: eapol_version int [ro]

      eapol version

Wi-Fi Radar
===========

With this api you can list the surrounding Wi-Fi access points, and Wi-fi channel usage.

This a new feature introduced in firmware 2.1.0 (api v2).

A scan is automatically done at AP startup, if you need to refresh the information you can use the scan api

Wi-Fi Neighbor Object
---------------------

WifiNeighbor has the following attributes:

.. json:object:: WifiNeighbor

   .. json:property:: bssid string [ro]

      neighbor bssid

   .. json:property:: ssid string [ro]

      neighbor ssid

   .. json:property:: band enum [ro]

       the band for which the combination can be used

       ========   ================
       band       Description
       ========   ================
       2d4g       2.4 GHz
       5g         5 GHz
       60g        60 GHz
       ========   ================

   .. json:property:: channel_width int [ro]

      neighbor channel_width

   .. json:property:: channel int [ro]

      neighbor primary channel

   .. json:property:: secondary_channel int [ro]

      neighbor secondary channel (0 for unused)

   .. json:property:: signal int [ro]

      signal attenuation in dB

   .. json:property:: capabilities WifiNeighborCap [ro]

      neighbor capabilities

.. json:object:: WifiNeighborCap

   .. json:property:: legacy bool [ro]

      neighbor uses legacy wifi (802.11a, 802.11b)

   .. json:property:: ht bool [ro]

      neighbor supports ht (802.11n)

   .. json:property:: vht bool [ro]

      neighbor supports vht (802.11ac)

Wi-Fi Planning
==============

With api v2 you can now specify time range when you want to enable your wifi.

Wi-Fi Planning Object
---------------------

.. json:object:: WifiPlanning

   .. json:property:: use_planning bool

      is the planning enabled

   .. json:property:: resolution int [ro]

      planning resolution (number of slots per day)

   .. json:property:: mapping str[]

      mapping for planning : "on" or "off"
      mapping[0] is monday at 0:0
      mapping[7 * resolution - 1] is sunday last slot

      (each slot has a duration of 60 * 24 / resolution minutes)

Wi-Fi MAC Filter API
====================

Wi-Fi MAC Filter object
-----------------------

WifiMacFilter has the following attributes:

.. json:object:: WifiMacFilter

   .. json:property:: id string [ro]

      filter id

   .. json:property:: mac string [ro]

      MAC address to filter

   .. json:property:: comment string

      comment

   .. json:property:: type enum

      ========= ===============================================
      type      Description
      ========= ===============================================
      whitelist if mac_filter is set to whitelist this station will be allowed
      blacklist if mac_filter is set to blacklist this station will be rejected
      ========= ===============================================

   .. json:property:: hostname string [ro]

      host name when available

   .. json:property:: host LanHost [ro]

      host information when available
