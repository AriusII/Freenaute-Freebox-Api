========
Contacts
========

The contact API allow to interact with the contact list stored on the
Freebox

Contacts Errors
===============

When attempting to access the contact API, you may encounter the
following errors:

======================           =====================================
error_code                       Description
======================           =====================================
noent                            no entry with this id
exists                           an entry already exists
no_match                         no entry matched your request
======================           =====================================

Contact Objects
===============

Contact Entry
-------------

Contact entries have the following properties

.. json:object:: ContactEntry

   .. json:property:: id int

       contact id

   .. json:property:: display_name string

       contact display name

   .. json:property:: first_name string

       contact first name

   .. json:property:: last_name string

       contact last name

   .. json:property:: company string

       contact company name

   .. json:property:: photo_url string

       contact photo URL

       *NOTE* the photo URL can be embedded (for instance
       "data:image/jpeg;base64,/9j/4AA [ ... ]")

   .. json:property:: last_update timestamp

       contact last modification timestamp

   .. json:property:: notes string

       contact last modification timestamp

   .. json:property:: addresses ContactAddress[]

       list of contact postal addresses

   .. json:property:: emails ContactEmail[]

       list of contact email addresses

   .. json:property:: numbers ContactNumber[]

       list of contact phone numbers

   .. json:property:: urls ContactUrl[]

       list of contact URL

Contact Number
--------------

Contact number have the following properties

.. json:object:: ContactNumber

   .. json:property:: id int

       address id

   .. json:property:: contact_id int

       id of the related contact

   .. json:property:: type enum

      Type of number

      ===============   =======================
      Type              Description
      ===============   =======================
      fixed             fixed phone
      mobile            mobile phone
      work              work
      fax               fax
      other             other
      ===============   =======================

   .. json:property:: number string

   .. json:property:: is_default bool

      is this number the preferred contact phone number

   .. json:property:: is_own bool

      is this number the Freebox owner number

Contact API
===========

----------------------

   Returns the collection of all :json:object:`ContactEntry`

   :param int group_id:      Return only the contacts that belong to this group

   .. sourcecode:: http

      GET /api/v4/contact/ HTTP/1.1
      Host: mafreebox.freebox.fr

Create a contact
----------------

.. http:post:: /api/v4/contact/

   Creates a new :json:object:`ContactEntry`

   **Example request**:

   .. sourcecode:: http

      POST /api/v4/contact/ HTTP/1.1
      Host: mafreebox.freebox.fr

   .. sourcecode:: javascript

      {
         "display_name": "Sandy Kilo",
         "first_name": "Sandy",
         "last_name":"Kilo"
      }

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "last_name": "Kilo",
              "company": "",
              "photo_url": "",
              "id": 10,
              "birthday": "",
              "last_update": 1372433423,
              "display_name": "Sandy Kilo",
              "notes": "",
              "first_name": "Sandy"
          }
      }

Delete a contact
----------------

.. http:delete:: /api/v4/contact/{id}

   Deletes the :json:object:`ContactEntry` with the given id.

   **Example request**:

   .. sourcecode:: http

      DELETE /api/v4/contact/1 HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true
      }

Contact Related objects API
===========================

Contact related entries such as phone numbers, addresses, URLs and
emails are all handled the same way.

Below we'll document the numbers API, you can use the same calls with
addresses, URL and emails.

Get the list of numbers for a given contact
-------------------------------------------

.. http:get:: /api/v4/contact/{contact_id}/[numbers|addresses|urls|emails]/

   Returns the collection of all :json:object:`ContactNumber` for a
   given contact

   **Example request**:

   .. sourcecode:: http

      GET /api/v4/contact/4/numbers/ HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": [
              {
                  "number": "+13374242",
                  "type": "fixed",
                  "id": 6,
                  "contact_id": 4,
                  "is_default": false,
                  "is_own": false
              },
              {
                  "number": "0611223344",
                  "type": "mobile",
                  "id": 5,
                  "contact_id": 4,
                  "is_default": false,
                  "is_own": false
              }
          ]
      }
