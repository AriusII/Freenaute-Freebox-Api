==============
Download Feeds
==============

The Freebox downloader supports subscribing to RSS feeds, for
automatic content download.

Download Feed object
====================

Download Feeds have the following attributes:

.. json:object:: DownloadFeed

   .. json:property:: id int [ro]

       id

   .. json:property:: status enum [ro]

      The feed can have the following status

      ===============   ======================
      Status            Description
      ===============   ======================
      ready             feed is up to date
      fetching          feed is updating
      error             there was an error trying to refresh this feed, see error
      ===============   ======================

   .. json:property:: url string [ro]

      Feed URL

   .. json:property:: title string [ro]

      Feed title (extracted from the RSS)

   .. json:property:: desc string [ro]

      Feed description (extracted from the RSS)

   .. json:property:: image_url string [ro]

      Feed image URL (extracted from the RSS)

   .. json:property:: nb_read int [ro]

      Number of read items in the feed

   .. json:property:: nb_unread int [ro]

      Number of unread items in the feed

   .. json:property:: auto_download bool

      If set to true, the downloader will automatically download new
      items

   .. json:property:: fetch_ts timestamp [ro]

      Last time the feed was fetched

   .. json:property:: pub_ts timestamp [ro]

      Last time the feed was published on remote server

   .. json:property:: error enum [ro]

      Error code (same as used in :json:object:`Download` or
      :json:object:`DownloadFile`).


Download Feed Errors
====================

When attempting to access the download feed API, you may encounter the
following errors:

======================         ======================
error_code                      Description
======================         ======================
feed_not_found                 No feed was found with the given id
item_not_found                 No feed item was found with the given id
feed_is_recent                 You are trying to update a feed that is already up to date
internal_error                 Internal error
======================         ======================


Download Feed API
=================

   Returns the collection of all :json:object:`DownloadFeed` feeds

Add a Download Feed
-------------------

.. http:post:: /api/v4/downloads/feeds/

   Creates a new :json:object:`DownloadFeed`.

   **Example request**:

   .. sourcecode:: http

      POST /api/v4/downloads/feeds/ HTTP/1.1
      Host: mafreebox.freebox.fr

      {
         "url": "http://www.nzb-rss.com/rss/Debian-unstable.rss"
      }

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true,
          "result": {
              "auto_download": false,
              "error": "none",
              "desc": "",
              "status": "ready",
              "nb_read": 0,
              "title": "",
              "image_url": "",
              "feed_id": 6,
              "url": "http://www.nzb-rss.com/rss/Debian-unstable.rss",
              "nb_unread": 0,
              "fetch_ts": 0,
              "pub_ts": 1350583600
          }

      }

Delete Download Feed
--------------------

.. http:delete:: /api/v4/downloads/feeds/{id}

   Deletes the :json:object:`DownloadFeed` and all the associated items.

   This will not alter the :json:object:`Download` tasks.

   **Example request**:

   .. sourcecode:: http

      DELETE /api/v4/downloads/feeds/1 HTTP/1.1
      Host: mafreebox.freebox.fr

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true
      }

Refresh a Download Feed
-----------------------

.. http:post:: /api/v4/downloads/feeds/{id}/fetch

   Remotely fetches the RSS feed and updates it.

   Note that if the remote feed specifies a TTL, trying to update
   before the ttl will result in feed_is_recent error

   **Example request**:

   .. sourcecode:: http

      POST /api/v4/downloads/feeds/2/fetch HTTP/1.1
      Host: mafreebox.freebox.fr


   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

      {
          "success": true
      }

Download Feed Item object
=========================

Each RSS :json:object:`DownloadFeed` contains feed items object


.. json:object:: DownloadFeedItem

   .. json:property:: id int [ro]

       id

   .. json:property:: feed_id int [ro]

       id of the :json:object:`DownloadFeed`

   .. json:property:: title string[ro]

      item title

   .. json:property:: desc string[ro]

      item description

   .. json:property:: author string [ro]

      item author

   .. json:property:: link string [ro]

      URL of the RSS feed attachment

   .. json:property:: is_read bool

      you can mark the item as read manually, or it is marked as read
      automatically when the item is downloaded

   .. json:property:: is_downloaded bool [ro]

      mark downloaded items, automatically set to true when RSS item
      is downloaded

   .. json:property:: fetch_ts timestamp [ro]

      timestamp of the item creation

   .. json:property:: pub_ts timestamp [ro]

      item publish timestamp

   .. json:property:: enclosure_url string [ro]

      enclosure URL (if specified in RSS feed)

   .. json:property:: enclosure_type string [ro]

      enclosure mime type (if specified in RSS feed)

   .. json:property:: enclosure_length int [ro]

      enclosure size in bytes (if specified in RSS feed)

Update a feed item
------------------

.. http:put:: /api/v4/downloads/feeds/{feed_id}/items/{item_id}

   Returns the collection of all :json:object:`DownloadFeedItems` for
   a given :json:object:`DownloadFeed`

   **Example request**:

   .. sourcecode:: http

      PUT /api/v4/downloads/feeds/2/items/2846 HTTP/1.1
      Host: mafreebox.freebox.fr

   .. sourcecode:: javascript

      {
          "is_read": true
      }

   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

     {
       "success": true
     }

--------------------

      Host: mafreebox.freebox.fr


   **Example response**:

   .. sourcecode:: http

      HTTP/1.1 200 OK
      Content-Type: application/json; charset=utf-8

   .. sourcecode:: javascript

     {
       "success": true
     }
